* Doom Emacs — Vim / Evil Editing & Navigation
Standard Vim motions, operators, and text objects via Evil, plus Doom's
additions. Normal mode unless noted. ★ = your custom binding from =config.el=.
** Modes
- ~Esc~ / ~C-g~ :: Return to normal mode
- ~i~ :: Insert mode
- ~v~ :: Visual (charwise)
- ~V~ :: Visual line
- ~C-v~ :: Visual block
- ~R~ :: Replace (overtype) mode
- ~:~ :: Ex command line
** Enter insert mode
- ~i~ / ~a~ :: Insert before / after cursor
- ~I~ / ~A~ :: Insert at first non-blank / end of line
- ~o~ / ~O~ :: Open new line below / above
- ~gi~ :: Resume insert at last insert spot
- ~C-r {reg}~ :: (in insert) paste register without leaving insert
** Motions — within a line
- ~h j k l~ :: Left / down / up / right
- ~0~ :: Start of line
- ~^~ :: First non-blank char
- ~$~ :: End of line
- ~g_~ :: Last non-blank char
- ~w~ / ~W~ :: Next word / WORD start
- ~e~ / ~E~ :: Next word / WORD end
- ~b~ / ~B~ :: Previous word / WORD start
- ~ge~ :: End of previous word
** Motions — find a char in the line
- ~f {c}~ / ~F {c}~ :: To next / previous occurrence of char
- ~t {c}~ / ~T {c}~ :: Till just before next / previous char
- ~;~ / ~,~ :: Repeat last f/t/snipe forward / backward
** Motions — across the document
- ~gg~ :: First line
- ~G~ :: Last line ( ~{n}G~ jumps to line n )
- ~{~ / ~}~ :: Previous / next paragraph
- ~(~ / ~)~ :: Previous / next sentence
- ~%~ :: Jump to matching bracket / pair
- ~H~ / ~M~ / ~L~ :: Top / middle / bottom of window
** Scrolling
- ~C-d~ / ~C-u~ :: Half page down / up
- ~C-f~ / ~C-b~ :: Full page forward / back
- ~C-e~ / ~C-y~ :: Scroll one line down / up
- ~zz~ :: Center current line
- ~zt~ / ~zb~ :: Current line to top / bottom
** Snipe (Doom default — overrides Vim's ~s~)
- ~s {c}{c}~ :: Jump forward to a 2-char match
- ~S {c}{c}~ :: Jump backward to a 2-char match
- ~;~ / ~,~ :: Repeat snipe forward / backward
- (For Vim's old ~s~ "substitute char", use ~cl~ instead)
** Operators (combine with any motion or text object)
- ~d~ :: Delete
- ~c~ :: Change (delete then insert)
- ~y~ :: Yank (copy)
- ~>~ / ~<~ :: Indent / outdent
- ~=~ :: Re-indent
- ~gu~ / ~gU~ :: Lowercase / uppercase
- =g~= :: Toggle case
- ~gc~ :: Comment / uncomment (Doom: evil-nerd-commenter)
- Double the operator to act on the whole line: ~dd~ ~cc~ ~yy~ ~>>~ ~gcc~ ~guu~
- Examples: ~dw~ delete word, ~ci"~ change inside quotes, ~d$~ delete to EOL, ~>ip~ indent paragraph
** Text objects (after an operator, or in visual mode)
- ~iw~ / ~aw~ :: Inner / a word
- ~iW~ / ~aW~ :: Inner / a WORD
- ~is~ / ~as~ :: Inner / a sentence
- ~ip~ / ~ap~ :: Inner / a paragraph
- ~i"~ ~a"~  ~i'~  ~i`~ :: Inside / around quotes
- ~i(~  ~ib~ :: Inside parentheses
- ~i{~  ~iB~ :: Inside braces
- ~i[~ :: Inside brackets
- ~i<~ :: Inside angle brackets
- ~it~ / ~at~ :: Inner / around an HTML/XML tag
- Examples: ~ci(~ change inside parens, ~dap~ delete a paragraph, ~yi"~ yank inside quotes
** Editing in normal mode
- ~x~ / ~X~ :: Delete char under / before cursor
- ~r {c}~ :: Replace single char with {c}
- ~R~ :: Replace mode (overtype)
- =~= :: Toggle case of char under cursor
- ~J~ :: Join line below (with a space)
- ~gJ~ :: Join without a space
- ~D~ :: Delete to end of line ( = ~d$~ )
- ~C~ :: Change to end of line ( = ~c$~ )
- ~Y~ :: Yank line ( = ~yy~ )
- ~.~ :: Repeat last change
- ~u~ :: Undo
- ~C-r~ :: Redo
** Yank & paste
- ~yy~ / ~Y~ :: Yank line
- ~p~ / ~P~ :: Paste after / before cursor
- ~"{reg} y~ :: Yank into named register {reg}
- ~"{reg} p~ :: Paste from register {reg}
- ~"+ y~ / ~"+ p~ :: Yank / paste via system clipboard
- ~"0 p~ :: Paste the last yank (skips deletes)
** Visual mode
- ~v~ / ~V~ / ~C-v~ :: Char / line / block selection
- ~o~ :: Jump to the other end of the selection
- ~gv~ :: Reselect the last visual selection
- ~d~ ~c~ ~y~ :: Delete / change / yank the selection
- ~>~ / ~<~ :: Indent / outdent selection
- ~u~ / ~U~ :: Lowercase / uppercase selection
- ~gc~ :: Comment the selection
- ~r {c}~ :: Replace every selected char with {c}
- (block) ~I~ / ~A~ :: Insert / append on every line, then ~Esc~
** Search in buffer
- ~/ {pat}~ / ~? {pat}~ :: Search forward / backward
- ~n~ / ~N~ :: Next / previous match
- ~*~ / ~#~ :: Search word under cursor forward / backward
** Marks & jumps
- ~m {a}~ :: Set mark {a}
- ~` {a}~ :: Jump to mark {a} (exact spot)
- ~' {a}~ :: Jump to mark {a} (line)
- ~`` ~ / ~'' ~ :: Jump back to where you were before the last jump
- ~C-o~ / ~C-i~ :: Older / newer position in the jump list
- ~g;~ / ~g,~ :: Older / newer change position
- ~gd~ :: Go to definition (Doom)
- ~gD~ :: Go to references (Doom)
- ~gf~ :: Go to file at point
- ~K~ :: Look up documentation at point (Doom)
** Macros & repeat
- ~q {reg}~ :: Start recording into register {reg}; press ~q~ again to stop
- ~@ {reg}~ :: Play macro {reg}
- ~@@~ :: Replay the last macro
- ~.~ :: Repeat the last edit
** Multiple cursors — ~gz~ prefix (Doom: evil-mc)
- ~gzm~ :: Place a cursor at every match of the symbol / selection
- ~gzz~ :: Toggle a cursor at point
- ~gzj~ / ~gzk~ :: Add a cursor and move down / up
- ~gzn~ / ~gzN~ :: Add a cursor at the next / previous match
- ~gzu~ :: Remove all extra cursors
- (Exact evil-mc keys can be confirmed live with which-key under ~gz~)
** Folding
- ~za~ :: Toggle fold under cursor
- ~zo~ / ~zc~ :: Open / close fold
- ~zr~ / ~zm~ :: Open / close one fold level everywhere
- ~zR~ / ~zM~ :: Open all / close all folds
** Custom — window navigation ★
- ~s-h~ / ~s-j~ / ~s-k~ / ~s-l~ :: Move to window left / down / up / right (Cmd+hjkl; works in normal, visual, and insert) ★
** Custom — org-mode editing ★ (inside org buffers)
- ~RET~ (insert) :: New list item when inside a list, otherwise a normal newline ★
- ~M-]~ / ~M-[~ :: Demote / promote heading or list item ★
- ~s-]~ / ~s-[~ :: Demote / promote (Cmd+brackets) ★
- ~SPC~ (insert) :: Typing ~- ** ~ at line start auto-converts the bullet into a heading ★
* Doom Emacs — Leader (SPC) Keybindings
Evil mode, ~SPC~ leader. Bindings marked ★ come from your =config.el= and are
placed in the section they belong to. C-c / Control equivalents are omitted by
design.
** Conventions
- ~SPC~ — global leader.
- ~SPC m~ — local leader (major-mode commands; in org buffers, the big org menu).
- Press ~SPC~ and pause — which-key shows live menus for any prefix below.

** Org Agenda — ~SPC o A~
- ~SPC o A a~ :: Agenda (day/week view)
- ~SPC o A t~ :: Global TODO list
- ~SPC o A m~ :: Match tags
- ~SPC o A M~ :: Match tags (all TODOs)
Your custom *Dashboard* view (=org-agenda-custom-commands=, key ~d~): run the
agenda dispatcher (~M-x org-agenda~) and press ~d~ — it stacks today's agenda +

file in ~/org/ and it appears automatically.

* Config Overview
** Locations
- Config: ~/.config/doom/ (config.el, init.el, packages.el)
- Doom install: ~/.config/emacs/
- doom binary: ~/.config/emacs/bin/doom
- Org files: ~/org/
- Snippets: ~/.config/doom/snippets/
** Sync workflow
- Edit init.el or packages.el → must run: doom sync → restart Emacs
- Edit config.el only → just restart (SPC q r) or eval
- Health check: doom doctor

* Troubleshooting Log
** Frozen Emacs
- C-g repeatedly, or C-] to abort recursive edit
- From terminal: pkill -SIGUSR2 Emacs (interrupt without killing)
** "Cannot open load file" on a package
- A use-package! block exists but no matching (package! ...) in packages.el
- Fix: add the package! line + doom sync
** Corrupt LSP server download
- rm -rf ~/.config/emacs/.local/etc/lsp/ then reinstall
