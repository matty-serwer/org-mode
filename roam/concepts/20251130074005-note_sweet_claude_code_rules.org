** Project Overview
A *macOS-first Roam Research clone* with bullet-based editing, two-way linking, and local-first SQLite storage via Tauri.
** Tech Stack (Locked Versions)
Package Version Notes React 19.1.0 Hooks only, no class components Vite 7.0.0 With =@vitejs/plugin-react= Remirror 3.0.0 ProseMirror-based editor Zustand 5.0.8 State management Tauri 2.x Desktop framework (Rust backend) TypeScript 5.6+ Strict mode enabled Tailwind CSS 3.4.1 Utility-first styling
*Do not upgrade or change these versions without explicit instruction.*
** Coding Conventions
*** TypeScript
- Strict mode is mandatory (=strict: true=)
- Use =noUncheckedIndexedAccess= and =noImplicitAny=
- Prefer type inference where obvious; explicit types for function signatures
- Use =interface= for object shapes, =type= for unions/intersections
*** React
- Functional components only (React 19 hooks)
- Prefer =useReducer= for complex state logic
- Co-locate component-specific hooks in the same file
- Use =useCallback= and =useMemo= only when profiling shows need
*** State Management (Zustand)
- One store per domain: =notesStore=, =editorStore=, =linksStore=
- Use =devtools= middleware in development
- Actions are async when calling Tauri IPC
*** Remirror Editor
- Extensions live in =src/components/Editor/extensions/=
- Each extension is a single file with clear responsibility
- Store editor content as ProseMirror JSON schema
*** Tauri IPC
- Commands defined in =src-tauri/src/commands/=
- Frontend calls via =invoke()= from =@tauri-apps/api=
- Always handle errors with =.map_err()= in Rust
- Return =Result<T, String>= from all commands
*** File Naming
- React components: =PascalCase.tsx=
- Hooks: =useCamelCase.ts=
- Utilities: =camelCase.ts=
- Rust files: =snake_case.rs=
*** Styling
- Tailwind utilities in JSX
- Minimal custom CSS (only for editor-specific overrides)
- Dark mode via Tailwind's =dark:= prefix
** Architecture Rules
1. *Local-first*: All data lives in SQLite. No network requests for core functionality.
1. *Tauri boundary*: React never touches filesystem directly. All persistence goes through Tauri commands.
1. *Link graph*: Two-way links are stored in the =links= table, not embedded in note content.
1. *Auto-save*: Notes save on blur and on a 5-second debounce interval.
** What NOT to Do
- No class components
- No =any= types (use =unknown= if truly unknown)
- No direct filesystem access from React
- No Electron patterns (this is Tauri)
- No Server Components (this is a local app)
- No external API calls for core features
- No inline styles (use Tailwind)
