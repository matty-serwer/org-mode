** 2-Day Roadmap
*** Day 1 — Setup & Core Pages
*Milestone 1: Environment (1–2 hrs)*
- Sign up for Shopify Partner account at partners.shopify.com[5]
- Create a Development Store, add 8–10 sample products with images, prices, and collections
- Create a new Next.js app: =npx create-next-app@latest --typescript= with Tailwind
- Install dependencies: =@shopify/hydrogen-react=, =graphql-request=
- Create a =.env.local= with your =SHOPIFY_STORE_DOMAIN= and =SHOPIFY_STOREFRONT_ACCESS_TOKEN= (from the dev store's Storefront API settings)
*Milestone 2: Data Layer (1 hr)*
- Set up a Shopify Storefront API client using =createStorefrontClient= from =hydrogen-react=
- Write your first GraphQL queries: fetch all products, fetch single product by handle
- Test queries in Shopify's built-in GraphiQL explorer first[3]
*Milestone 3: Product Listing Page (1–2 hrs)*
- Build =/= — Homepage with featured collections grid
- Build =/products= — Product listing page with all products, filtered by collection
- Use =<Image>= from hydrogen-react for optimized Shopify CDN images
- Style with Tailwind (responsive grid, hover states)
*Milestone 4: Product Detail Page (1–2 hrs)*
- Build =/products/[handle]= — dynamic route
- Display product images, title, price using =<Money>=, variants selector, description
- Add to Cart button wired to =useCart()= from hydrogen-react
- Cart drawer or cart page with line items, quantity update, remove
-----

*** Day 2 — Polish, Cart, Checkout & Portfolio Presentation
*Milestone 5: Cart & Checkout (1–2 hrs)*
- Implement =CartProvider= at the app root
- Build a slide-out cart drawer using cart state from =useCart()=
- Wire the "Checkout" button to Shopify's hosted checkout URL (Storefront API returns a =checkoutUrl=)[3]
- Test a full add-to-cart → checkout flow in test mode using Shopify's bogus gateway
*Milestone 6: Search & Collection Pages (1–2 hrs)*
- Build =/collections/[handle]= — collection-filtered product grid
- Add a search bar that queries Shopify's =search= endpoint
- Add a simple nav with links to collections
*Milestone 7: SEO & Performance (1 hr)*
- Add dynamic =<Head>= meta tags per product (title, description, OG image)
- Add =next/image= integration for LCP optimization
- Verify Lighthouse score — headless Shopify stores regularly hit 95+[6]
*Milestone 8: Portfolio Finishing (1–2 hrs)*
- Add a custom font + branded color scheme (your own aesthetic — this is your portfolio piece)
- Deploy to Vercel (free tier, 2-min deploy with =vercel --prod=)
- Write a clean README with screenshots for your Fiverr gig images
- Record a 60–90 second Loom walkthrough of the storefront — buyers love video previews
-----

** Day-by-Day Time Breakdown
Block Day 1 Day 2 Morning Partner account + dev store setup, Next.js scaffold Cart & checkout flow Afternoon GraphQL data layer + product listing page Search + collection pages Evening Product detail page + cart state SEO, Vercel deploy, portfolio polish

** Key Tips Going In
- *Use the GraphiQL app in your Shopify dev store* to build and test all your queries before writing any Next.js code — it saves a ton of debugging time[3]
- =@shopify/hydrogen-react= is framework-agnostic (works with Next.js, not just Hydrogen's Remix setup), so highlight that in your gig — it signals you understand the ecosystem[4]
- Shopify's test checkout uses a *"Bogus Gateway"* — no real card needed, just enter =1= as the card number to simulate a successful order
- The finished project gives you a real live URL to link from your Fiverr gig, which is a major trust signal for buyers
