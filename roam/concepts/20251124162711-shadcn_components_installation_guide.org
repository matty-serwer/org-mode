#+title: Shadcn Components Installation Guide
#+filetags: :concept:
#+date: 2025-11-24
- Core Components
  - button
  - input
  - select
  - dropdown-menu
  - table
  - dialog
  - form
  - sonner
  - skeleton
  - avatar
  - card
  - tabs
  - navigation-menu
- Feature-Specific Components
  - calendar
  - checkbox
  - radio-group
  - slider
  - table
  - progress
  - tooltip
  - alert
  - badge
  - sheet
- Additional Components (if available)
  - date-picker
  - drawer
- Installation Commands
  - Each component can be installed using:
  - =npx shadcn-ui@latest add [component-name]=
- Notes
  - Input types (Text, Email, Password, Numeric) all use the same input component
  - Modal/Dialog is installed as dialog
  - Notification/Toast is toast
  - Avatar/User icon is avatar
  - Card & List Item - list items are typically built with existing components, so just card is needed
  - Tabs/Navigation split into tabs and navigation-menu
  - Tag/Chip is typically badge in shadcn
  - Drawer may be sheet or drawer depending on the implementation
  - Some components like drag-and-drop, file upload, stepper/wizard, barcode scanner, charts, and timeline may not be available as standard shadcn components and would need custom implementation or third-party libraries
  - Install Core Components:
    - =npx shadcn@latest add button input select dropdown-menu table dialog form sonner skeleton avatar card tabs navigation-menu=
