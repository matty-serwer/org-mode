** The Basics
*Quick Navigation & Folding*
#+begin_src markup
TAB          - Cycle visibility of current heading (folded → children → all)
S-TAB        - Cycle visibility of entire document
C-c C-n/p    - Next/previous heading
C-c C-u      - Go up to parent heading

#+end_src
*Basic Structure* - Org files are just plain text with special markup:
#+begin_src org
* Top Level Heading
** Second Level Heading
*** Third Level
Some content here

- bullet list item
- another item

1. Numbered list
2. Another item

#+end_src

*** What Makes It Magical:
*1. TODO Management* - Press =SPC m t= (or =C-c C-t= in vanilla Emacs) to cycle through TODO states:
#+begin_src markup
* TODO Write documentation
* DOING Write documentation  
* DONE Write documentation

#+end_src
*2. Scheduling & Deadlines*
#+begin_src org
* TODO Fix authentication bug
  SCHEDULED: <2025-01-15 Wed>
  DEADLINE: <2025-01-20 Mon>

#+end_src
- =C-c C-s= to schedule
- =C-c C-d= to set deadline
- =C-c a a= to see your agenda view
*3. Code Blocks (The Game Changer)* This is where Org Mode gets magical:
#+begin_src org
#+begin_src javascript
const greeting = "Hello from Org Mode!";
console.log(greeting);
#+end_src

#+end_src
Hit =C-c C-c= inside a code block to *execute it directly* and see results inline. Works with dozens of languages.
*4. Quick Capture (*=SPC X=*)*
#+begin_src markup
SPC X    - Opens capture menu
- Pick a template
- Type your note/task
- Save it (C-c C-c)

#+end_src
*5. Agenda Views* (=SPC o A= or =SPC n a=) See all your TODOs, deadlines, and scheduled items across all your org files in one view.

** 3. 🔗 *Links & Navigation* (The "Everything is Connected" Magic)

   ...content here...

#+end_src
*Try this:*
- =C-c C-l= - Insert a link
- =C-c C-o= - Open link at cursor
- =SPC m l l= - Insert link (Doom Emacs shortcut)
Links can point to:
- Other org files: =[[file:~/notes/project.org]]=
- Headings in files: =[[file:notes.org::*Heading Name]]=
- Web URLs: =[[https://example.com][Link Text]]=
- Files: =[[file:~/Documents/report.pdf]]=

** 5. *Agenda Views* (The Game Changer)
This is where Org Mode becomes magical. It aggregates ALL your TODO items and scheduled tasks across ALL your org files into one unified view.
#+begin_src org
* TODO Finish portfolio site
  DEADLINE: <2025-01-15 Wed>
  
* MEETING Client call
  SCHEDULED: <2025-01-12 Sun 10:00-11:00>

#+end_src
- =C-c C-s= to schedule an item
- =C-c C-d= to set a deadline
- =C-c a a= to open the agenda (shows your week at a glance)
- =C-c a t= to see all TODOs across all files
** 6. *Capture Templates* (Quick Inbox)
Press =SPC X= (in Doom) to quickly capture a thought without breaking flow:
#+begin_src elisp
;; In your config
(setq org-capture-templates
      '(("t" "Todo" entry (file+headline "~/org/inbox.org" "Tasks")
         "* TODO %?\n  %i\n  %a")
        ("n" "Note" entry (file+headline "~/org/notes.org" "Notes")
         "* %?\n  %i\n  %a")))

#+end_src
** 7. *Code Blocks* (Literate Programming)

- Mix documentation with executable code!

* Why People Rave About Org Mode
1. *Plain text future-proofing*: Your data isn't locked in proprietary formats
1. *Everything in one place*: TODOs, notes, code, documentation
1. *The Agenda*: Unified view of your entire life across multiple files
1. *Keyboard-driven workflow*: No context switching to mouse
1. *Infinite customization*: It grows with you
1. *Literate programming*: Mix docs and code seamlessly
1. *Link everything*: Your knowledge base becomes interconnected
-----

1. Start simple with a =todo.org= file

1. Add scheduling when you're comfortable
1. Set up agenda views
1. Then explore capture templates
