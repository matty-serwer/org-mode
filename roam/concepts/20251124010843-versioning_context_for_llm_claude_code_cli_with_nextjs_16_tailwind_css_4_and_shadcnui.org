- Add to =~/.zshrc= for persistence

** Proven Workflow: "Plan-Parallel-Iterate-Commit" (PPI-C)
- This is the top-recommended workflow from 2025 sources (Anthropic engineering tips, X threads on sub-agents, [[DEV.to][DEV.to]] guides)
- Battle-tested for agentic/vibe coding: Claude plans holistically, spawns sub-agents for parallel exploration (e.g., 3 UI variants), iterates via bash execution, and commits atomically
- Expect 80% less manual debugging with MCP
*** High-Level Steps
- *Plan*: Use =claude plan= with =.claude/CLAUDE.md= for stack-aware blueprint
- *Parallel*: Dispatch sub-agents (e.g., one for API, one for UI) via git worktrees for safe sandboxes
- *Iterate*: Bash mode + MCP for code gen/execution; screenshot/debug as needed
- *Commit*: Auto-changelog + PR review

- Language: TypeScript (strict mode; infer types where possible)
- Other: ESLint + Prettier; Git for versioning

*** Coding Guidelines
- *Components*: Always use Shadcn primitives + Tailwind (e.g., =<Button variant="outline" className="w-full">=)
  - Avoid HTML tags; compose with =cn()= utility
- *Next.js*: Server Components by default; use ='use client'= sparingly
  - Fetch in server actions/loaders
- *Tailwind 4*: Leverage new utils (e.g., =opacity-50=, =grid-cols-[repeat(auto-fit,minmax(200px,1fr))]=)
  - No v3 fallbacks
- *Best Practices*: Functional components + hooks; error boundaries; accessibility (ARIA via Radix)
  - TDD: Write tests first
- *MCP Integration*: Query Shadcn MCP at localhost:8080 for live docs/props
  - Prefix prompts: "Per Shadcn MCP: Generate a Card with hover effects."
*** Allowed Tools (Curate for Safety)
- =bash=: Run npm scripts, git commands (e.g., =claude bash "npm run lint --fix"=)
- =read/write/edit=: Code files only (no system files)
- =grep/glob=: Search codebase
- =mcp-query=: Fetch from Shadcn/Tailwind MCP (e.g., =mcp-query shadcn button props=)
- =screenshot=: Debug UI (upload to Claude for analysis)
