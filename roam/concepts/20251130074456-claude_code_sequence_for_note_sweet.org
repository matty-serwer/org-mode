** Step 10: Create SQLite Schema
Create =src-tauri/src/db/schema.sql=:
#+begin_src sql
CREATE TABLE IF NOT EXISTS notes (
  id TEXT PRIMARY KEY,
  title TEXT NOT NULL,
  content TEXT NOT NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  parent_id TEXT,
  sort_order INTEGER,
  FOREIGN KEY (parent_id) REFERENCES notes(id) ON DELETE CASCADE
);

CREATE TABLE IF NOT EXISTS links (
  source_id TEXT NOT NULL,
  target_id TEXT NOT NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (source_id, target_id),
  FOREIGN KEY (source_id) REFERENCES notes(id) ON DELETE CASCADE,
  FOREIGN KEY (target_id) REFERENCES notes(id) ON DELETE CASCADE
);

CREATE INDEX IF NOT EXISTS idx_links_target ON links(target_id);
CREATE INDEX IF NOT EXISTS idx_notes_parent ON notes(parent_id);

#+end_src

** Using Claude Code
*** Basic Usage
From your project root:
#+begin_src bash
claude

#+end_src
Claude Code will automatically read =.claude/CLAUDE.md= for project context.
*** Example Prompts
*Start with Phase 1 MVP:*
#+begin_src markup
Implement the BulletEditor component in src/components/Editor/BulletEditor.tsx.
Use Remirror v3 with React 19 hooks. Start with basic bullet list support.

#+end_src
*Add Tauri commands:*
#+begin_src markup
Create the notes CRUD commands in src-tauri/src/commands/notes.rs.
Include create_note, get_note, update_note, delete_note, and list_notes.
Use sqlx for async SQLite queries.

#+end_src
*Wire up state:*
#+begin_src markup
Implement notesStore.ts using Zustand 5.0.8.
It should call Tauri commands for persistence and cache notes in a Map.

#+end_src
*** Tips for Claude Code
1. *Reference versions explicitly* - "Use Remirror v3" not just "use Remirror"
1. *Point to specific files* - "Edit src/store/notesStore.ts"
1. *One feature at a time* - Don't ask for the whole editor in one prompt
1. *Test incrementally* - Run =npm run tauri dev= between major changes
