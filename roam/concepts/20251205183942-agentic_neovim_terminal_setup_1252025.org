*Recommended Terminal Neovim Setup: AI-Powered Solo Dev Workflow*
You’re welcome—love the enthusiasm! Based on your React/Spring Boot/Python stack, LazyVim base, and focus on non-agentic AI (Claude/OpenCode for scaffolding/reviews without auto-edits), here’s a *singular, streamlined setup* that’s terminal-native and ready for 2025 workflows. This prioritizes speed: instant startup, seamless context sharing (e.g., visual selections to AI), and diff-based reviews for full-app prototypes.
We’ll use:
- *OpenCode* (CLI/TUI agent): For heavy lifts like “scaffold React CRUD + Spring endpoints + Python migrations.” It’s model-agnostic (Claude default), privacy-first, and terminal-optimized.
- *One Native-Running nvim Plugin*: sudo-tee/opencode.nvim – A lightweight bridge that runs OpenCode’s TUI /inside/ nvim (via embedded terminal) but adds nvim-native smarts like auto-sending selections/buffers as context. (It’s “native-running” as it embeds and hooks directly into nvim APIs for context/diffs, without external processes unless you toggle.)
- *One Provider-Based nvim Plugin*: olimorris/codecompanion.nvim – Multi-provider chat/diff tool with Anthropic (Claude) adapter. Use it for quick, targeted prompts (e.g., “refactor this Python script”) that stream to buffers—provider-based means easy swaps (Claude today, local Ollama tomorrow).
- *Other Essentials*: A minimal plugin suite for LSP/diffs/terminals, plus Tmux for multi-pane persistence (OpenCode in one pane, nvim in another if needed). No bloat—total plugins: ~8 new ones on LazyVim.
This setup lets you: Select code in nvim → Send to OpenCode for full scaffolds (review diffs) → Tweak with codecompanion’s Claude chat → Ship solo. Community vibe (Reddit/X 2025 threads): This combo is “terminal godmode” for fireproofing—faster than Cursor, extensible for your langs. 2 5 22 34
*High-Level Architecture*
- *Terminal Layer*: Tmux (sessions: nvim main, OpenCode side-pane).
- *Editor*: LazyVim with LSP pre-tuned for your stack.
- *AI Flow*: OpenCode for agentic planning/edits (approval-only) → codecompanion for inline Claude tweaks.
- *Hardware Prereqs*: macOS/Linux (assumed); Neovim 0.10+; 8GB+ RAM for local models if desired.
- *Cost*: Free (OpenCode + plugins); Claude API key for heavy use (~$20/mo for Sonnet).

*1. Prep Your Terminal Environment (15 mins)*
- Install Tmux: brew install tmux (macOS) or apt install tmux (Linux). Why? Persistent panes for nvim + OpenCode without context-switching.
- Install OpenCode: curl -fsSL [[https://opencode.ai/install][https://opencode.ai/install]] | bash. Verify: opencode --version (should show v1.2+ as of Dec 2025).
-
  - Auth: opencode auth login → Select “anthropic” → Paste ANTHROPIC_API_KEY (get from console.anthropic.com).
  - Quick Config (~/.opencode.json):

  -   "defaultProvider": "anthropic",
  -   "providers": { "anthropic": { "model": "claude-3-5-sonnet-20241022" } },
  -   "agents": { "build": { "tools": ["edit", "bash", "lsp"] }, "plan": { "tools": ["read", "search"] } },
  -   "lsp": { "autoLoad": true },
  -   "ui": { "theme": "system" }  // Matches nvim dark mode
  - }
  - 
  - Test: opencode → Prompt “Explain a basic React hook” → Approve/quit. LSP should detect TS if in a project.
- Set Env: Add to +/.zshrc or +/.bashrc: export ANTHROPIC_API_KEY=sk-... and export PATH="$HOME/.opencode/bin:$PATH". Reload: source ~/.zshrc.
- (Optional) Ollama for Local: brew install ollama; ollama pull llama3.2 – Add to OpenCode config for offline Python tweaks.

*3. Install & Configure AI Plugins (20 mins)*
- Create lua/plugins/ai.lua in your LazyVim config:
  return {
-   -- Native-Running: opencode.nvim (embeds TUI with nvim context)
-   { "sudo-tee/opencode.nvim", opts = {
-     ui = { icon_style = "nerdfonts" },  -- Matches LazyVim icons
-     output = { tools = { show_output = true }, rendering = { markdown_debounce_ms = 250 } },
-     input = { text = { wrap = false } },
-     completion = { file_sources = { enabled = true } },  -- Auto-includes your React/Spring files
-     prompt_guard = { enabled = true }  -- Blocks accidental sends
-   }, keys = { { "oo", "OpencodeToggle", desc = "Toggle OpenCode" } } },
- 
-   -- Provider-Based: codecompanion.nvim (Claude chat/diffs)
-   { "olimorris/codecompanion.nvim", dependencies = { "nvim-treesitter/nvim-treesitter" }, config = function()
-     require("codecompanion").setup({
-       adapters = { anthropic = { api_key_name = "ANTHROPIC_API_KEY", model = "claude-3-5-sonnet-20241022" } },
-       strategies = { chat = { adapter = "anthropic" } },  -- Default to Claude
-       display = { open = "current" },  -- Inline buffers, no popups
-       keymaps = { apply = "", toggle = "cc" }  -- Review/apply diffs
-     })
-   end, cmd = "CodeCompanionChat" },
- 
-   -- Essentials: Diffs, Terminals, Markdown (for AI outputs)
-   { "sindrets/diffview.nvim", lazy = false },  -- Review OpenCode edits
-   { "akinsho/toggleterm.nvim", version = "*", opts = { open_mapping = [[]], direction = "horizontal" } },  -- Embed OpenCode
-   { "MeanderingProgrammer/render-markdown.nvim", ft = "markdown", opts = { file_types = { "markdown", "txt" } } },  -- Render AI plans
- }
