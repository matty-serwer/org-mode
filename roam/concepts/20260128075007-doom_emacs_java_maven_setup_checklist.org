#+title: Doom Emacs Java Maven Setup Checklist
#+filetags: :concept:
#+date: 2026-01-28
** Initial Setup
- [ ] *Enable Java module in *=init.el=
  - Uncomment =:lang java +lsp +tree-sitter=
  - Run =doom sync= after changes
- [ ] *Install LSP server*
  - Eclipse JDT Language Server installs automatically on first Java file open
  - Or manually: =M-x lsp-install-server RET jdtls=
- [ ] *Configure Java in *=config.el=
  
  #+begin_src elisp
  (after! lsp-java
    (setq lsp-java-format-settings-url "path/to/eclipse-formatter.xml" ; optional
          lsp-java-format-settings-profile "GoogleStyle" ; optional
          lsp-java-save-actions-organize-imports t))
  
  #+end_src
- [ ] *Install Maven CLI* (if not already)
  - macOS: =brew install maven=
  - Verify: =mvn --version=
- [ ] *Set Java home* (in =config.el=)
  
  #+begin_src elisp
  (setq lsp-java-java-path "/path/to/java"
        lsp-java-configuration-runtimes '[(:name "JavaSE-17" :path "/path/to/jdk-17")])
  
  #+end_src
- [ ] *Enable project management*
  - Projectile works out-of-box with =pom.xml=
  - Run =SPC p p= to test project detection
** Essential Packages to Consider
- [ ] *Enable magit* (Git integration) - usually enabled by default
- [ ] *Enable format module* in =init.el= for auto-formatting
- [ ] *Optional: Install *=mvn.el= for Maven tasks
  
  #+begin_src elisp
  ;; In packages.el(package! mvn)
  
  #+end_src

** Maven Operations
*** Using LSP Commands
- =SPC c x= - Execute command → search for "maven"
- Common tasks via =M-x=:
  - =lsp-java-spring-initializr= - Create Spring Boot project
*** Using Terminal
- =SPC o t= - Open terminal in project root
- Run: =mvn clean install=, =mvn test=, etc.
*** With mvn.el (if installed)
- =M-x mvn-clean=
- =M-x mvn-compile=
- =M-x mvn-test=

** Quick Tips for IntelliJ Users
1. *Think in terms of prefixes*: =SPC c= = code actions, =SPC f= = file operations, =SPC g= = git, =SPC p= = project
1. *Use *=SPC ?= to search all keybindings
1. *Evil mode*: =i= to insert, =Esc= to normal mode (like IntelliJ's Vim plugin)
1. *Maven builds*: Just use the terminal (=SPC o t=) - it's often fastest
1. *Save often*: =:w= in normal mode or =SPC f s=
** Common Gotchas
- *First Java file takes time*: JDT Language Server downloads/indexes on first open
- *Project not recognized*: Make sure =pom.xml= exists in project root
- *LSP not starting*: =M-x lsp-doctor= to diagnose
- *Slow completions*: JDT needs warmup time after startup
