#+title: Doom Emacs Workspaces
#+filetags: :concept:
#+date: 2025-12-01
- /Doom Emacs includes built-in workspace management via persp-mode with the following capabilities:/
- Key Commands
  - *Create workspaces*: =SPC TAB n= or =+workspace/new=
  - *Switch workspaces*: =SPC TAB TAB= or =+workspace/switch-to=
  - *Save workspace session*: =SPC TAB s= or =+workspace/save-session=
  - *Load workspace session*: =SPC TAB l= or =+workspace/load-session=
- Session Persistence Options
  - Enable desktop save mode: =(desktop-save-mode 1)=
  - Use Doom's session management:
  - #+begin_src markup
    (after! persp-mode   (setq persp-auto-save-opt 1))  ; Auto-save every minute
    #+end_src
- Features
  - Automatic periodic saving
  - Named session saving
  - Buffer isolation between workspaces
  - Preservation of window layouts
  - Restoration of open buffers, window arrangements, current buffers, and working directories
    - This functionality is ideal for switching between different projects or workflows.
