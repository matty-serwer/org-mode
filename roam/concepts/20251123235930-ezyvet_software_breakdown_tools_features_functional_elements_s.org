* *EzyVet Software Breakdown: Tools, Features & Functional Elements. S*
- [[id:213f83fa-e135-4ce9-86e6-248b43dbb80e][Vet Sweet]] Research
- *Purpose*: Technical analysis of IDEXX EzyVet veterinary practice management system to inform development of similar software
- *Architecture*: Cloud-based, browser-accessible, single-server (AWS infrastructure), real-time sync capabilities
- Core System Architecture
  - Platform Foundation
    - Deployment: Fully cloud-based SaaS solution
    - Access: Any device with modern web browser (Chrome recommended)
    - Offline Mode: Local caching with automatic sync when connection restored
    - Infrastructure: AWS (Amazon Web Services) hosting
    - Security: Bank-level encryption, role-based access control, 2FA authentication
    - Data Sync: Real-time updates across all connected devices
  - Technical Integration Capabilities
    - API: RESTful API for custom integrations and third-party connections
    - Data Lake: Enterprise-level data warehouse service for advanced analytics
    - Native Integrations: IDEXX diagnostic suite, Xero accounting, SmartFlow, Vet Radar
    - Webhook Support: Event-driven architecture for real-time data exchange
- TIER 1: Essential Core Systems
  - 1. Client & Patient Records Management
    - Client Database
      - Contact information storage (email, phone, address)
      - Financial history and credit ratings
      - Communication preferences and opt-in/opt-out settings
      - Multi-pet household management
      - Referral source tracking
    - Patient Records (Clinical Module)
      - Patient demographics and identification
      - Complete medical history with timestamp tracking
      - Treatment history and prescription records
      - Vaccination records and schedules
      - Patient demeanor status flags
      - Multi-user concurrent editing capability
      - Attachment storage (documents, images, forms)
    - Key Functional Elements
      - Quick patient lookup without opening full record
      - Master Problems list for diagnosis tracking
      - Historical data access (12+ months)
      - Patient profile snapshots
  - 2. Appointment Scheduling System
    - Core Scheduling Features
      - Visual calendar dashboard (day/week/month views)
      - Drag-and-drop appointment manipulation
      - Customizable appointment types and durations
      - Appointment status tracking (booked → checked in → in progress → discharged)
      - Multi-resource scheduling (rooms, staff, equipment)
      - Blocking and availability management
    - Client-Facing Booking
      - Online scheduling via Vello client portal
      - Two modes: Direct booking or appointment requests (requires approval)
      - Configurable time slots (15/30/60 minute increments)
      - Provider selection by clients
      - Wellness visits vs. sick visits differentiation
    - Automation
      - Automatic email/SMS appointment reminders
      - Appointment confirmation messages
      - Planning Guides for template-based scheduling
      - Wellness plan subscription appointment allocation
    - Key Functional Elements
      - Real-time calendar availability checking
      - Color-coded appointment statuses
      - One-click access to patient records from appointments
      - Notification system for new bookings (red indicator)
  - 3. Invoicing & Payments System
    - Invoice Management
      - Drag-and-drop line item manipulation
      - Customizable invoice columns and sublines
      - Real-time invoice building during consultation
      - Bulk discount functionality
      - Multiple payment method support
      - Partial payment and split billing
      - Estimate creation and conversion to invoices
    - Payment Processing
      - ezyVet Payments: Integrated payment processor
      - Automatic patient information sync to records
      - Auto write-back to practice management system
      - Remote payment links (email/SMS)
      - Payment allocation to multiple invoices
      - Credit and refund management
    - Billing Triggers
      - Automatic charge capture from clinical activities
      - Template-based product bundles
      - Service fee configuration
      - Time-based billing rules
      - Diagnostic test auto-billing
    - Key Functional Elements
      - Draft invoice preview before finalization
      - Approval workflow for invoices
      - Payment reconciliation automation
      - Invoice status tracking (pending, approved, paid, overdue)
  - 4. Inventory Management
    - Stock Control
      - Real-time inventory level tracking
      - Multi-location inventory support
      - Batch tracking and lot numbers
      - Expiration date monitoring with alerts
      - Automatic reorder point notifications
      - Seasonal reorder point customization (monthly variations)
    - Purchase Orders
      - Automated PO generation at threshold levels
      - Supplier integration for direct ordering
      - Receiving workflow with auto-update
      - Backorder management
      - Invoice matching and reconciliation
    - Pricing Management
      - Product markup rules (percentage or fixed)
      - Multi-tier pricing structures
      - Product bundles and package deals
      - Dynamic pricing by appointment type or client
      - Automatic price updates from supplier integrations
    - Mobile Inventory Tools
      - ezyVet Scan App: Mobile barcode scanning
      - Inventory counts on mobile devices
      - Inventory transfers between locations
      - Real-time sync with main system
      - Comment/notes on inventory items
    - Key Functional Elements
      - FIFO (First In, First Out) rotation alerts
      - Stock movement reporting
      - Wastage tracking (expired products)
      - Inventory value calculations
  - 5. Clinical Workflow & Documentation
    - SOAP Notes Structure
      - Subjective, Objective, Assessment, Plan format
      - Customizable clinical record layouts
      - Automatic layout filtering by appointment type
    - Clinical Templates & Picklists
      - Pre-configured history templates
      - Tab-through data entry (no manual typing)
      - Variable-driven templates
      - Procedure-specific templates (e.g., spay, neuter, dental)
      - Automatic note population from templates
    - Diagnostic Integration
      - Direct diagnostic requests to equipment
      - Real-time result integration (IDEXX VetConnect PLUS)
      - Automatic result attachment to patient record
      - Analyte graphs for trend spotting
      - Differential diagnosis guidance (IDEXX DecisionIQ)
    - Prescription Management
      - E-prescribing capability
      - Medication dispensing workflow
      - Restricted Veterinary Medicine (RVM) compliance tracking
      - Prescription refill requests from client portal
      - Medication history tracking
    - Key Functional Elements
      - Clinical note approval workflow
      - Document templates (handouts, discharge instructions)
      - Remote signature capture
      - Voice dictation support (device-dependent)
      - Master Problems list for ongoing diagnosis tracking

      - Performance Reports

    - Reporting Features
      - Custom date range selection
      - Automated report scheduling
      - Export to Excel/CSV
      - Real-time data (cloud advantage)
      - Drill-down capability to source records
      - Multi-department filtering
    - Key Functional Elements
      - Interactive report manipulation
      - Visual data representation (pie charts, graphs)

  - 8. Staff & Role Management

    - Time Clock System
      - Clock in/out functionality

      - Overtime calculations
      - Staff performance monitoring
    - Task Management
      - Work List dashboard

    - Key Functional Elements

  - 9. Wellness Plans & Subscriptions
    - Membership Management
      - Subscription-based wellness plans

      - Service inclusion tracking (what's used vs. available)

    - Appointment Allocation

    - Vet Radar
      - Visual patient flow tracking
      - Task lists by staff member
      - Patient location tracking
      - Automated charge synchronization

    - Key Functional Elements
      - Multi-patient view
      - Color-coded status indicators
      - Medication administration logging
      - Discharge workflow

    - IDEXX Web PACS
      - Automatic image attachment to patient records

      - DICOM format support
      - X-ray and ultrasound storage
      - Image sharing for consultations
    - VetConnect PLUS
      - Holistic view of all IDEXX diagnostics
      - Historical result graphing
      - Real-time test order status tracking
      - Client-friendly result summaries
      - Expert interpretive guidance
    - IDEXX DecisionIQ
      - Machine learning pattern detection
      - Patient-specific interpretive assistance
      - Cross-modality data analysis (lab, imaging, history)
      - Next-step recommendations
    - Key Functional Elements
      - Automatic charge capture on image orders
      - Pre-loaded request forms
      - Result notification system

      - Multiple patient consult tracking
      - Voice dictation note capture
      - Medication/vaccination/procedure logging
      - Draft invoice preview in field
      - Automatic sync when in range
      - Financial history access (12 months)

      - Download appointments before leaving clinic
      - Data persistence during offline periods
      - Bulk patient treatment application

    - Product Supplier Integrations

      - Multi-pet booking management

- Technical Implementation Insights
  - Database Structure Implications
    - Normalized relational database (based on reporting and record linkage capabilities)
    - Entity relationships: Client → Patient → Appointment → Invoice → LineItems
    - Audit tables: Track changes, user actions, timestamps
    - Template/configuration tables: Store customizable elements
  - UI/UX Patterns
    - Dashboard-centric navigation: Multiple tabs for different workflows
    - Contextual access: Click through to related records
    - Color-coded status indicators: Visual feedback system
