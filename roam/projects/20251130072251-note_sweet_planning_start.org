* Roam Research Clone - Tech Stack & Setup Guide
** Executive Summary
This is a *macOS-first Roam Research clone* built with modern React, featuring:
- *Bullet-based editor* with indentation-based hierarchy
- *Two-way linking* with backlink previews
- *Local-first storage* (SQLite via Tauri)
- *Native macOS app* experience
- *Low friction development* with Claude Code CLI
-----

** Tech Stack (Latest Stable Versions - November 2025)
*** Frontend Framework
- *React 19.1.0* (=/facebook/react= v19_1_1)
  - Use React 19 hooks exclusively (no class components)
  - Leverage latest hooks: =useReducer=, =useActionState=
  - Server Components NOT needed for local-first app
*** Build Tool
- *Vite 7.0.0* (=/vitejs/vite= v7.0.0)
  - Instant HMR for rapid development
  - Lightning-fast builds
  - Configured with =@vitejs/plugin-react= for Fast Refresh
*** Text Editor
- *Remirror v3* (=/remirror/remirror=)
  - React-first, built on ProseMirror
  - Bullet list support out-of-the-box
  - Custom extension system for linking
  - *Why Remirror over Tiptap 3?*
    - Better React integration (no contentEditable-React conflicts)
    - More mature bullet/list handling
    - Built-in extension patterns for custom nodes (links, backlinks)
    - Smaller bundle than Tiptap with cloud services
*** State Management
- *Zustand v5.0.8* (=/pmndrs/zustand= v5.0.8)
  - Minimal boilerplate, max flexibility
  - DevTools middleware available
  - Middleware for localStorage sync (for macOS auto-save)
  - Perfect for local-first apps
*** Local Storage
- *SQLite via Tauri*
  - Tauri v2 (=/tauri-apps/tauri=) provides native backend
  - Use =@tauri-apps/api= for frontend-to-Rust communication
  - Rust backend uses =sqlx= (async SQLite with compile-time query checking)
  - Rationale: Self-contained database, zero server overhead, native macOS integration
*** Desktop Framework
- *Tauri v2.x* (=/websites/v2_tauri_app=)
  - Build single native binary for macOS (+ Linux/Windows for future)
  - Rust backend with full filesystem + database access
  - Secure IPC between React frontend and Rust backend
  - No Electron overhead (~170MB native binary vs 300MB+ Electron)
  - Native macOS features: app menu, file dialogs, notifications
*** Styling
- *Tailwind CSS v3.4*
  - Utility-first CSS for rapid UI development
  - Dark mode support out-of-the-box
  - Minimal custom CSS needed
*** Testing (Optional - Phase 2)
- *Vitest* (=/websites/vitest_dev=)
  - Unit tests for Remirror extensions
  - Zustand store tests
  - Native ES modules, Vite-compatible
*** Type Safety
- *TypeScript 5.6+*
  - Strict mode enabled
  - Full type safety for Tauri IPC commands
  - Remirror extension types

** Database Schema (SQLite)
#+begin_src sql
-- Notes table
CREATE TABLE notes (
  id TEXT PRIMARY KEY,
  title TEXT NOT NULL,
  content TEXT NOT NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  parent_id TEXT,
  sort_order INTEGER,
  FOREIGN KEY (parent_id) REFERENCES notes(id) ON DELETE CASCADE
);

-- Two-way links (edges in the link graph)
CREATE TABLE links (
  source_id TEXT NOT NULL,
  target_id TEXT NOT NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (source_id, target_id),
  FOREIGN KEY (source_id) REFERENCES notes(id) ON DELETE CASCADE,
  FOREIGN KEY (target_id) REFERENCES notes(id) ON DELETE CASCADE
);

-- Full-text search index (optional, Phase 2)
CREATE VIRTUAL TABLE notes_fts USING fts5(
  id UNINDEXED,
  title,
  content,
  content = notes,
  content_rowid = id
);

import { useRemirrorManager, useCommands } from '@remirror/react';

export function BulletEditor({ noteId }: { noteId: string }) {
  const { manager, state, setState } = useRemirrorManager({
    extensions: [
      new BulletExtension(),
      new LinkExtension(),
    ],
  });

  const commands = useCommands();
  const editorStore = useEditorStore((s) => s);
  const notesStore = useNotesStore((s) => s);

  const handleSave = async () => {
    const content = JSON.stringify(state.doc);
    await notesStore.updateNote(noteId, content);
  };

  return (
    <RemirrorTestChain manager={manager} state={state} setState={setState}>
      <div contentEditable className="editor" />
    </RemirrorTestChain>
  );
}

*** Two-Way Links: Detection & Storage
#+begin_src typescript
// linkParser.ts
export function extractLinks(content: string): string[] {
  const regex = /\[\[([^\]]+)\]\]/g;
  return Array.from(content.matchAll(regex), m => m[1]);
}

// When note updates, sync links table in Tauri:
notesStore.updateNote = async (id, content) => {
  const links = extractLinks(content);
  await invoke('update_links_from_note', { noteId: id, targets: links });
};
#+end_src
*** Tauri Command Example (Rust)
#+begin_src rust
// src-tauri/src/commands/backlinks.rs
use tauri::State;
use crate::db::Database;

#[tauri::command]
pub async fn get_backlinks_to_note(
    note_id: String,
    db: State<'_, Database>,
) -> Result<Vec<String>, String> {
    let conn = db.get_connection()
        .map_err(|e| e.to_string())?;
    
    let mut stmt = conn.prepare(
        "SELECT source_id FROM links WHERE target_id = ?"
    ).map_err(|e| e.to_string())?;
    
    let backlinks: Vec<String> = stmt.query_map([note_id], |row| {
        row.get(0)
    }).map_err(|e| e.to_string())?
        .collect::<Result<Vec<_>, _>>()
        .map_err(|e| e.to_string())?;
    
    Ok(backlinks)
}
#+end_src

// store/notesStore.ts
import create from 'zustand';
import { devtools, persist } from 'zustand/middleware';
import { invoke } from '@tauri-apps/api';

interface NotesStore {
  notes: Map<string, Note>;
  currentNoteId: string;
  
  updateNote: (id: string, content: string) => Promise<void>;
  deleteNote: (id: string) => Promise<void>;
  createNote: (title: string, parent?: string) => Promise<string>;
  loadNotes: () => Promise<void>;
}

export const useNotesStore = create<NotesStore>()(
  devtools(
    persist(
      (set) => ({
        notes: new Map(),
        currentNoteId: '',
        
        updateNote: async (id, content) => {
          await invoke('update_note', { id, content });
          set((state) => ({
            notes: new Map(state.notes).set(id, {
              ...state.notes.get(id)!,
              content,
            }),
          }));
        },
        
        // ... other methods
      }),
      { name: 'notes-store' }
    )
  )
);

** Troubleshooting
*** HMR Not Working?
- Ensure =npm run tauri dev= is running (starts both Vite + Tauri)
- Check Tauri config: =src-tauri/tauri.conf.json=
*** SQLite Locked?
- Tauri handles connections via connection pool
- Ensure Rust commands use =?= operator for error propagation
*** Remirror Serialization?
- Store as JSON schema (ProseMirror format)
- Deserialize in editor with =EditorManager.create()=
*** Claude Code Syntax Errors?
- Verify =.claude-code-config.json= version pinning
- Run =npm run type-check= to validate TypeScript
