* [[id:9aca374d-a41f-4d13-9de6-3a3a3350aac6][🍰 SnipFlow]] - Instant Code Snippet Manager for [[id:ccc4b6f5-e2be-4941-968a-8f65c5906fe8][NeoVim]]
- /A git-backed, fzf-powered snippet library with seamless LazyVim integration./ 
-  
*** =Space + s + s= - Search Snippets (Primary)
- Opens fzf picker in vertical split
- Full interactive search with live preview
- Arrow keys to navigate, Enter to copy
- Close with =:q=, paste with =p=
*** =Space + s + i= - Insert Snippet
- Prompts for search term
- Inserts directly at cursor position
- Fast workflow for known snippets
*** =Space + s + d= - Snippets Directory
- Changes working directory to ~/snippets
- For editing and adding new snippets
** Terminal Commands
*** Basic Usage
- =snip= - Browse all snippets with fzf
- =snip react= - Search for snippets matching "react"
- =snip hook= - Fuzzy search for "hook"
- =snippets= - Navigate to ~/snippets directory
*** fzf Navigation (inside snip)
- *Arrow keys* - Move up/down through results
- *Enter* - Copy selected snippet to clipboard
- *Ctrl-E* - Edit snippet in $EDITOR
- *Ctrl-O* - Open snippet directory in Finder
- *ESC* - Cancel and exit
*** fzf Search Operators (type in search box)
- ='term= - Exact match (e.g., ='useState=)
- =^prefix= - Must start with (e.g., =^react/=)
- =suffix$= - Must end with (e.g., =.tsx$=)
- =!term= - Exclude (e.g., =!python=)
- =term1 | term2= - OR operator (e.g., =react | vue=)
- =term1 term2= - AND operator (e.g., =react hook=)
*** Search Examples
- =snip ary= - Finds "array-methods.js" (fuzzy)
- =snip react hook= - React files containing "hook"
- =snip !python= - Everything except Python
- =snip .tsx$= - Only TypeScript React files
- =snip middleware | route= - Express middleware or routes

** Workflows
*** LazyVim
1. *Browse & paste:* =Space-s-s= → search → Enter → =:q= → =p=
1. *Quick insert:* =Space-s-i= → type search → Enter
1. *Edit snippets:* =Space-s-d= → =:e category/file.ext= → save
*** Terminal
1. *Standard:* =snip= → type to search → Enter → paste
1. *Pre-filtered:* =snip react= → browse React only → Enter
1. *Fuzzy:* =snip ust= → finds "useState-hook" → Enter
