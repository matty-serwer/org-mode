  # Work Sweet
  
  **A modern, keyboard-first project management tool that doesn't suck.**
  
  ![TaskFlow Demo](./docs/demo.gif)
  
  ## ⚡ The Problem
  
  Traditional PM tools are cluttered. Creating a task requires clicking through 6 fields you don't need. The UI becomes unreadable with 20+ tasks.
  
  ## ✨ The Solution
  
  **Frictionless task creation**: Type, press enter, done. Title and description in one flow.
  
  **Slash commands**: Type `/priority` for quick actions. No hunting through menus.
  
  **Visual clarity**: Bold colors that actually help you parse information, not corporate beige.
  
  ![Task Creation](./docs/task-creation.gif)
  
  ## 🎯 Key Features
  
  ### 1. Intelligent Task Input
  - Single textarea interface
  - Press Enter to convert text to title
  - Slash commands for quick properties
  
  ### 2. Slash Command Menu
  - `/priority` - Set urgency level
  - `/due` - Add deadline
  - `/assign` - Assign team member
  - `/checklist` - Create sub-tasks
  
  ### 3. Smart Filters
  - Quick access to: All, My Tasks, Urgent, This Week
  - One-click project filtering
  
  ### 4. Visual Priority System
  - **Red**: Urgent - do now
  - **Orange**: High - do today
  - **Blue**: Normal - this week
  - **Gray**: Low - when you can
  
  ## 🛠 Tech Stack
  
  **Frontend**
  - Next.js 16 (App Router)
  - React 19
  - TypeScript
  - Tailwind CSS 4
  - React Query (data fetching)
  - dnd-kit (drag & drop)
  - Tiptap (rich text)
  
  **Backend**
  - Java 17
  - Spring Boot 3.x
  - Spring Security (JWT)
  - PostgreSQL
  - JPA/Hibernate
  
  **Deployment**
  - Frontend: Vercel
  - Backend: Railway
  - Database: Neon
