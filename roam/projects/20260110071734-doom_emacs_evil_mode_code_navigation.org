#+title: 💾 💥 Doom Emacs (Evil Mode) Code Navigation
#+filetags: :project:
#+date: 2026-01-10
** Basic Movement
- =j= - Move down
- =k= - Move up
- =h= - Move left
- =l= - Move right
- =w= - Move forward over words
- =b= - Move backward over words
- =e= - Move to end of word
- =0= - Move to start of line
- =^= - Move to first non-blank character
- =$= - Move to end of line
- =gg= - Go to first line of file
- =G= - Go to last line of file
- =#G= - Go to line #
- =#j= - Go # lines down
- =#k= - Go # lines up
- =H= - First line in window
- =M= - Middle line in window
- =L= - Last line in window
** Code-Specific Navigation
- =%= - Jump to matching bracket/paren
- =[[= - Jump to previous function
- =]]= - Jump to next function
- =gd= - Go to definition
- =gD= - Go to references
- =K= - Show documentation
- =C-o= - Jump back (previous location)
- =C-i= - Jump forward (next location)
** Search
- =/= - Search forward
- =?= - Search backward
- =n= - Next occurrence
- =N= - Previous occurrence
- =*= - Search word under cursor forward
- =#= - Search word under cursor backward
** Editing
- =i= - Insert before cursor
- =a= - Insert after cursor
- =I= - Insert at start of line
- =A= - Insert at end of line
- =o= - Open line below
- =O= - Open line above
- =x= - Delete character
- =dd= - Delete line
- =dw= - Delete word
- =d$= - Delete to end of line
- =d^= - Delete to start of line
- =cc= - Change (replace) line
- =cw= - Change word
- =C= - Change to end of line
- =r= - Replace single character
- =u= - Undo
- =C-r= - Redo
- =.= - Repeat last command
** Code Editing
- =>>= - Indent line
- =<<= - Un-indent line
- ==== - Auto-indent line
- =>%= - Indent code block
- =gc= - Comment/uncomment (motion)
- =gcc= - Comment/uncomment line
- =gJ= - Join lines without space
- =J= - Join lines with space
** Visual Mode
- =v= - Visual character mode
- =V= - Visual line mode
- =C-v= - Visual block mode
- =gv= - Reselect last selection
** Doom Leader Keys (SPC)
- =SPC /= - Search in project
- =SPC s s= - Search buffer
- =SPC f f= - Find file
- =SPC b b= - Switch buffer
- =SPC c d= - Go to definition
- =SPC c D= - Go to references
- =SPC c k= - Show documentation
- =SPC c r= - Rename symbol
- =SPC c f= - Format buffer
** Window/Split Navigation
- =SPC w v= - Split vertical
- =SPC w s= - Split horizontal
- =SPC w h/j/k/l= - Navigate splits
- =SPC w d= - Delete window
