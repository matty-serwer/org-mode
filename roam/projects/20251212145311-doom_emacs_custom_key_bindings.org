* 💾 💥 [[id:11b4987f-47fd-460c-8b2c-8a4fc0c76150][Doom Emacs]] Custom Key Bindings
- LTD Custom Key Bindings
  - *Reference Prefix* (=SPC r=)
    - =SPC r c= — CSS references
    - =SPC r j= — Java references
    - =SPC r r= — React TS refs
  - *Visual/Window Prefix* (=SPC v=)
    - =SPC v v= — Vertical split with new buffer
    - =SPC v -= — Horizontal split with new buffer
  - *Window Navigation* (global)
    - =⌘-h= — Move to left window
    - =⌘-j= — Move to down window
    - =⌘-k= — Move to up window
    - =⌘-l= — Move to right window
