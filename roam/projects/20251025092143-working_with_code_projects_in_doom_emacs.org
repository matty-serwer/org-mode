* 💾 💥 Working with [[id:f2b909aa-190a-47d2-92f4-089f6da157ca][Code Projects]] in [[id:11b4987f-47fd-460c-8b2c-8a4fc0c76150][Doom Emacs]]
-  
** Open an Existing Project
- Launch [[id:11b4987f-47fd-460c-8b2c-8a4fc0c76150][Doom Emacs]]
- Press =SPC p p= to open Projectile's project finder
- Select your project directory
- If [[id:cf99828a-1122-49e1-80d4-d4b1193a7e0e][LSP]] isn't auto-starting, press =SPC c l= in a source file
- Verify setup by opening a key file with =SPC p f=
** Add an Existing Project
- Launch [[id:11b4987f-47fd-460c-8b2c-8a4fc0c76150][Doom Emacs]] (not in an existing project)
- Navigate to the project directory:
  - Press =SPC .= for fuzzy search
  - Or use =SPC o o= for ace-window
- Open a file in the project directory
- Press =SPC p a= to add as a known project
- Switch to the project with =SPC p p=
- Verify by searching files with =SPC p f=
** Ensuring Project Persistence
- [[id:24a11107-00af-41a1-935c-ecde27f80958][Projectile]] stores projects in cache files
- Projects persist across sessions
- Use =SPC p i= to invalidate and reindex if cache seems outdated
- Remove projects with =SPC p d= if needed

** Efficient Window Layout for Coding
- *Setup process*
  - [[id:a3eec4af-4e99-48ce-b2bc-987be6125579][File explorer]]
    - Toggle [[id:26b60faa-68c9-469e-a596-79e5136bf998][Treemacs]]: =SPC o t=
    - Navigate project directories
  - *Window splitting*
    - Horizontal split: =SPC 2=
    - Vertical split: =SPC 3=
    - Focus single window: =SPC 1=
    - Switch [[id:446e09da-6a91-4ae5-a217-0ab3b9cf35fe][buffers]]: =SPC b b=
  - *Terminal integration*
    - Open [[id:6f427d68-0ecc-4e4a-a0a1-9ebcd673d3d9][vterm]]: =SPC o T=
    - Open [[id:d3a0d0c2-2492-4163-9894-a5946f6016bb][eshell]]: =SPC '=
    - Run development servers
    - Resize windows: =SPC o e= or mouse drag
  - *Additional tools*
    - [[id:91c71ea3-9f3f-40e3-a5c2-4f2d53bb5ff9][Git]] ([[id:4ef42f00-0571-4a76-ab3a-74cac5b84d3e][Magit]]): =SPC g g=
    - [[id:f0d522c2-ec16-4591-9c69-8c5620ae0563][REPL]]: =SPC m s i=
  - *Layout management*
    - Reopen project: =SPC p p=
    - Switch perspectives: =SPC p P=
