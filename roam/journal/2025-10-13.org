- Shell Command: Write .component Filenames to a text file
  
  #+begin_src markup
  ls -1 *.component 2>/dev/null | grep -v "^UAD " > component_list.txt
  #+end_src
  - 
  - Part 1: ls -1 *.component
    • ls - Lists directory contents
    • -1 - Forces output to one file per line (instead of columns)
    • *.component - Wildcard pattern that matches all files ending with ".component"
  - Part 2: 2>/dev/null
    • 2> - Redirects stderr (error messages) to a different location
    • /dev/null - A special file that discards anything written to it
    • This prevents error messages from appearing if no .component files are found
  - Part 3: | (pipe)
    • Takes the output from the left command and feeds it as input to the right command
    • Connects ls output to grep input
  - Part 4: grep -v "^UAD "
    • grep - Searches for patterns in text
    • -v - Inverts the match (shows lines that DON'T match the pattern)
    • "^UAD " - Pattern that matches lines starting with "UAD " (^ means "beginning of line")
  - Part 5: > component_list.txt
    • > - Redirects the final output to a file
    • component_list.txt - The name of the output file that will be created
  - Overall flow:
  - List .component files → Hide errors → Filter out "UAD " files → Save to text file
