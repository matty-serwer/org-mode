    - Here’s an enhanced version of the bullet steps for each workflow, emphasizing *navigation actions*: how to change focus between windows and buffers, open/close splits, manage buffers, and move around efficiently in Doom Emacs with Evil mode. Each workflow covers the common navigation tasks you’ll need for full-stack work.
      -----
      
      *Workflow 1: Treemacs + Vterm + Split Navigation*
      -----
      
      *Workflow 2: Consult + LSP + Eshell Navigation*
      -----
      
      *Workflow 3: Dired Navigation + Multi-window*
      -----
      
      *Quick Navigation Tricks in Doom Evil Mode*
      -----
      
      If you want a single “cheat sheet” for navigation hotkeys, just ask!
      Sources
      - *Switch to another window (split):*
        - =C-w w= (cycle windows); or with Doom leader: =SPC w [h|j|k|l]= (move left/down/up/right)
        - Highlights border of active window
      - *Change to buffer in current window:*
        - =SPC b b= (buffer list, use fuzzy search, press enter)
        - New buffer shown in active window
      - *Open a new buffer/file/split:*
        - =SPC f f= (open file, fuzzy), or from Treemacs, select with arrow keys, =RET=
        - Opens in present window by default
      - *Create a new vertical/horizontal split:*
        - Vertical: =SPC w v=; Horizontal: =SPC w s=
        - Two windows, each shows buffer
      - *Close current window/split:*
        - =SPC w q=
        - Removes that window, focus jumps to next
      - *Close current buffer:*
        - =:bd= (buffer delete); or =SPC b d=
        - Buffer removes from list, window remains or closes to another buffer
      - *Cycle through buffers:*
        - =:bnext= / =:bprev= or =SPC b n= / =SPC b p=
      - *Switch focus between Treemacs/sidebar and main:*
        - Use =C-w w= repeatedly (or arrow key =SPC w h= to jump to left sidebar)
      - *Quick jump with Evil:*
        - =CTRL + o= (jump back), =CTRL + i= (jump forward)
        - Moves cursor like Vim jumplist
      - *Switch between open buffers:*
        - =SPC b b= (consult, pick buffer), =SPC TAB= (toggle last buffer)
        - Buffer jumps into active window
      - *Create split and focus:*
        - Vertical: =SPC w v=; Horizontal: =SPC w s=
        - =SPC w h/j/k/l= to jump between splits
      - *Open new file:*
        - =SPC f f= (find file), enter name, press enter to open in active window
        - For new file, =SPC f n= type filename
      - *Close buffer (file):*
        - =:bd= or =SPC b d=
      - *Close window/split:*
        - =SPC w q=
      - *Move between windows:*
        - Repeat =SPC w w=, or directional =SPC w h/j/k/l=
      - *Jump to errors/lines from Flycheck/LSP:*
        - Use =SPC e l= (to list errors) and =RET= to jump, or =:cnext=/=:cprev= for next/prev error
      - *Focus Eshell and switch back:*
        - After =SPC o e= (opens Eshell), change windows with above navigation or close Eshell with =exit=, or =SPC w q=
      - *Navigate in Dired directory browser:*
        - Move up/down: arrow keys or =j/k=
        - Enter folder/visit file: =RET=
        - Go up one directory: =-= or =u=
      - *Open file in split:*
        - Create split: vertical =SPC w v=, horizontal =SPC w s=
        - Focus target window, open file with =RET= in Dired
      - *Switch between splits:*
        - =SPC w h/j/k/l= to move focus
      - *Close current window/split:*
        - =SPC w q=
      - *Close buffer:*
        - =:bd= or =SPC b d=
      - *Cycle/open buffer:*
        - =SPC b b= (buffer list)
      - *Quick file creation in Dired:*
        - =+= (new file/folder, in selected dir), type name, enter
      - *Kill Dired buffer:*
        - =:bd= or =SPC b d=
      - *Switch focus with Evil mode:*
        - Use =C-w w=; or leader directional =SPC w h/j/k/l=
      - *Window cycling:* =C-w w=
      - *Directional window move:* =SPC w h= (left), =SPC w l= (right), =SPC w k= (up), =SPC w j= (down)
      - *Buffer prompt:* =SPC b b=
      - *Close window:* =SPC w q=
