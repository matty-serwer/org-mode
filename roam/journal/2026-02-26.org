    *3. Update your config*
    Replace your current capture templates and add agenda files. Your config already has most of this, just consolidate:
    
    #+begin_src elisp
    ;; Tell agenda which files to scan for todos
    (setq org-agenda-files '("~/org/inbox.org"
                              "~/org/work.org"
                              "~/org/personal.org"
                              "~/org/music.org"
                              "~/org/journal.org"))
    
    ;; Refile targets - any heading in these files, up to 2 levels deep
    (setq org-refile-targets '((org-agenda-files :maxlevel . 2)))
    (setq org-refile-use-outline-path t)           ; show full path in completion
    (setq org-outline-path-complete-in-steps nil)  ; single helm completion, not two-step
    
    ;; Capture templates
    (after! org
      (setq org-capture-templates
            '(("i" "Inbox" entry
               (file "~/org/inbox.org")
               "* %?\n  %U")
    
              ("t" "Todo" entry
               (file "~/org/inbox.org")
               "* TODO %?\n  %U")
    
              ("m" "Music Idea" entry
               (file+headline "~/org/music.org" "Ideas")
               "* IDEA %?\n  %U\n  Key: \n  BPM: \n  Vibe: ")
    
              ("j" "Journal" entry
               (file+datetree "~/org/journal.org")
               "* %?\n  %U"))))
    
    #+end_src

    *5. Navigation you'll actually use*
    What Key Jump to heading in current file =SPC s i= Search across all org files =SPC n s= Open agenda =SPC o A= Capture =SPC X= Refile current heading =C-c C-w= Fold/unfold all =S-TAB= Fold/unfold current =TAB=
    -----
    
    That's the whole system. Everything else you can add later when you feel a specific need for it.
    - =SPC X= → pick template → type → =C-c C-c=
    - =SPC o A= → shows all todos and scheduled items across all files
    - Open =inbox.org=
    - Cursor on a heading
    - =C-c C-w= → type destination (e.g. =work/LEMR=) → Enter → it's gone
