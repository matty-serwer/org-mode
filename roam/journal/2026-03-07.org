- [[id:605906e2-a379-4916-be3e-8d084d3bbaed][ULXD4Q — Setting Channels from Freq Sheet]]
  -----
  
  *Appendix*
  - Power on receiver
  - Select Ch 1 → Menu → Radio Frequency → MHz
  - Dial to assigned frequency → ENTER
  - Power on transmitter → align IR windows → press Sync on receiver
  - Confirm SYNC DONE, verify freq matches on both displays
  - Repeat for Ch 2–4
  - IR sync pushes the frequency from receiver to transmitter — you set the MHz on the receiver side only, then sync
  - If the transmitter shows G:-- Ch:-- after sync, that's normal — the frequency is still correctly set even if it doesn't map to a named group/channel slot
  - Confirm your band (G50, H50, etc.) matches the frequencies on the sheet before you start — if they're out of range, nothing will work and it's not a setup error
  - On the ULXD4Q, each of the 4 channels has its own independent menu — make sure you're in the right channel's settings before dialing
  - If the coordinator is running Wireless Workbench on a network, they may push frequencies remotely — ask before manually setting anything so you don't conflict with their deployment
- Receiver & Transmitter Setup
  - Receiver (ULXD4Q)
    - Set frequency
      - Menu → Radio Frequency → MHz
    - Set gain
      - Menu → Gain
    - Name channel
      - Menu → Channel Name
    - Lock front panel
      - Menu → Device Utilities → Lock
    - Save preset
      - Menu → Device Utilities → System Presets → Save
  - Transmitter (ULXD1/ULXD2)
    - IR sync to receiver
      - Power on → align IR windows → Sync button on receiver
    - Set RF mute (no RF on powerup)
      - Hold EXIT during power-on
    - Set mute mode
      - Menu → Mute Mode
    - Check battery level
      - Displayed on LCD at startup or in menu
    - Lock controls
      - Menu → Lock
