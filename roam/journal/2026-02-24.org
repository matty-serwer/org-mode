- TouchMCU Project: [[https://github.com/NicoG60/TouchMCU][https://github.com/NicoG60/TouchMCU]]
  QuickStart
  ∙ Go to the Releases section on the GitHub page and download the .tosc file variant that matches your DAW (there are DAW-specific builds)
  ∙ On your Mac, download and install TouchOSC Bridge from [[hexler.net][hexler.net]] — it runs silently in the background and creates a virtual MIDI port called “TouchOSC Bridge”
  ∙ Make sure your iPhone and Mac are on the same local Wi-Fi network
  ∙ Open TouchOSC on your iPhone, tap the settings/connection panel, go to the Bridge section — your Mac should appear automatically; select it
  ∙ In the MIDI section of TouchOSC connections, select <Bridge> as the MIDI output
  ∙ Import the downloaded .tosc file into TouchOSC (you can AirDrop it to your phone or open it via Files and share to TouchOSC)
  ∙ In LUNA, add a new control surface and select Mackie Control Universal — set input and output both to TouchOSC Bridge
  ∙ Hit play and the layout should sync up — if faders don’t reflect current state, look for a “Reset” or “Re-sync” option in LUNA’s control surface settings
  One heads-up: since you’re on iPhone rather than iPad, the layout will be cramped — TouchMCU was designed with iPad in mind. You may find yourself using it primarily for transport, fader banking, and the master fader rather than all 8 channels at once. Worth knowing before you dig in.​​​​​​​​​​​​​​​​

  - *Music Production Battle Plan*
    - *Beat Starter Kit*
      - Browse old projects, extract 20-30 drum arrangements you vibe with
      - Bounce each as Full Mix + K/S/T stems, name by feel/genre
      - Drop into one Ableton folder for quick drag-and-drop starts
    - *The Diva Doctrine*
      - Watch 10 Diva tutorials in one sitting, save one patch per category as you go
      - Build a Diva Creative Template track (Diva → Soundtoys/UAD chain → sends)
      - Add a pre-armed Moog Bus track to template so it's ready when you have space
      - Broken patch in old project? Swap in Diva and move on — don't rescue the past
    - *Mix Template* /(after 2-3 new sketches exist)/
      - Build Ableton mix template with routing/busses pre-configured
      - Test on a new sketch first — don't solve mixing problems you don't have yet
    - *Stem DJ Sessions* /(anytime, no pressure)/
      - Rip stems from reference tracks, remix/arrange for fun
      - Steal arrangement ideas, stay in Ableton on low-energy days
    - *Don't do yet*
      - Convert synth patches to Sampler
      - Organize all 500 projects
      - Build a perfect template before making music
