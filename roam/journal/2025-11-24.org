  - Adding New [[id:3390a25a-e948-46a4-bce4-0daf4e77c747][Utility Classes]] in [[id:53fea805-0c99-41dd-bd98-0ae28bae9fb9][Tailwind CSS]] for use with Any Component including [[id:522853c2-b75b-4bc6-b8fa-76b03dace8ab][shadcn/ui]] Components
    - To add new colors, you need to add them to your CSS file under the =:root= and =dark= pseudo-classes. Then, use the =@theme inline= directive to make the colors available as CSS variables.
      app/globals.css
      
      #+begin_src markup
      Copy:root {  --warning: oklch(0.84 0.16 84);  --warning-foreground: oklch(0.28 0.07 46);} .dark {  --warning: oklch(0.41 0.11 46);  --warning-foreground: oklch(0.99 0.02 95);} @theme inline {  --color-warning: var(--warning);  --color-warning-foreground: var(--warning-foreground);}
      #+end_src
      You can now use the =warning= utility class in your components.
      
      #+begin_src markup
      Copy<div className="bg-warning text-warning-foreground" />
      #+end_src
  - Choosing [[id:3390a25a-e948-46a4-bce4-0daf4e77c747][Utility Classes]] or [[id:3e765a11-f9f8-4859-a37c-57f57273df8f][CSS Variables]] for use with [[id:53fea805-0c99-41dd-bd98-0ae28bae9fb9][Tailwind CSS]] and, if you'd like, [[id:522853c2-b75b-4bc6-b8fa-76b03dace8ab][shadcn/ui]]
    - You can choose between using CSS variables (recommended) or utility classes for theming.
      *CSS Variables*
      
      #+begin_src markup
      Copy<div className="bg-background text-foreground" />
      #+end_src
      To use CSS variables for theming set =tailwind.cssVariables= to =true= in your =components.json= file.
      components.json
      
      #+begin_src markup
      Copy{  "style": "new-york",  "rsc": true,  "tailwind": {    "config": "",    "css": "app/globals.css",    "baseColor": "neutral",    "cssVariables": true  },  "aliases": {    "components": "@/components",    "utils": "@/lib/utils",    "ui": "@/components/ui",    "lib": "@/lib",    "hooks": "@/hooks"  },  "iconLibrary": "lucide"}
      #+end_src
      *Utility classes*
      
      #+begin_src markup
      Copy<div className="bg-zinc-950 dark:bg-white" />
      #+end_src
      To use utility classes for theming set =tailwind.cssVariables= to =false= in your =components.json= file.
      components.json
      
      #+begin_src markup
      Copy{  "style": "new-york",  "rsc": true,  "tailwind": {    "config": "",    "css": "app/globals.css",    "baseColor": "neutral",    "cssVariables": false  },  "iconLibrary": "lucide",  "aliases": {    "components": "@/components",    "utils": "@/lib/utils",    "ui": "@/components/ui",    "lib": "@/lib",    "hooks": "@/hooks"  }}
      #+end_src
      *Convention*
      We use a simple =background= and =foreground= convention for colors. The =background= variable is used for the background color of the component and the =foreground= variable is used for the text color.
      The =background= suffix is omitted when the variable is used for the background color of the component.
      Given the following CSS variables:
      
      #+begin_src markup
      Copy--primary: oklch(0.205 0 0);--primary-foreground: oklch(0.985 0 0);
      #+end_src
      The =background= color of the following component will be =var(--primary)= and the =foreground= color will be =var(--primary-foreground)=.
      
      #+begin_src markup
      Copy<div className="bg-primary text-primary-foreground">Hello</div>
      #+end_src
