      - *PowerShell Cleanup Script (Option A)*
        - Deletes designated folders (Documents, Desktop, Downloads, temp dirs) on shutdown or startup, logs what was removed, can be extended to cover edge cases as they're discovered
        - Setup: write and test script +4–8hrs, deploy via USB or Group Policy +2–4hrs, no server needed; +free, maybe +$0–50 in your time materials
        - Maintenance: ~free, occasional script updates as edge cases surface; low ongoing hours but not zero — edge cases will surface
      - *Reboot Restore Rx / Deep Freeze — Local Only (Option C basic)*
        - Freeze software installed on each machine, every reboot discards all session changes automatically, zero tech discipline required, very fast reset (reboot time only)
        - Setup: install on 50 machines +1 day hands-on, free tier (Reboot Restore Rx) or +$30–50/machine one-time (Deep Freeze); no server required
        - Maintenance: ~free ongoing; thaw/update/refreeze cycle required for any intentional change, manageable if machines come back to shop
      - *Deep Freeze Cloud / Reboot Restore Rx Pro — Remote Capable (Option C enterprise)*
        - Same as above plus push thaw, update, and refreeze commands remotely over internet without physical access — machines never need to come home for a reset
        - Setup: +1 day install + cloud console config; +$40–60/machine/year (Deep Freeze Cloud), ~$15–25/machine/year (RRRx Pro)
        - Maintenance: ~$2,000–3,000/yr for 50 machines; minimal hours once configured, update cycles require planned thaw windows
      - *Clonezilla USB Imaging (Option B — manual)*
        - Full drive restore to golden image via bootable USB, guaranteed clean slate, all software intact and consistent, client files and config drift completely eliminated
        - Setup: create golden image +4–8hrs, create 50 bootable USBs +2–4hrs; ~free (Clonezilla is open source); no server required but someone must physically touch each machine
        - Maintenance: free; +15–30 min per machine per restore cycle, image needs updating when software changes (+2–4hrs per update)
      - *Clonezilla Server + PXE Boot — Local Network (Option B — networked)* /(requires local server)/
        - Same full image restore as above but laptops boot from the network at the shop, no USB needed, can image multiple machines simultaneously, much faster at scale
        - Setup: configure server + PXE environment +1–2 days, requires a dedicated machine or Windows Server at the shop; +free software, server hardware ~$300–800 if not already owned
        - Maintenance: +free ongoing; still requires laptops to be physically at the shop on the local network; image updates +2–4hrs
      - *Acronis Cyber Protect — Networked Imaging with UI (Option B — polished)* /(requires local server or cloud)/
        - Same as Clonezilla networked but with a proper management dashboard, scheduled imaging, better error handling, more accessible for non-technical staff to run
        - Setup: +1 day; +$50–80/machine/year or ~$500–800 flat for small business perpetual license
        - Maintenance: ~$500–1,000/yr; minimal hands-on hours, image updates handled through GUI
      - *Windows Update for Business + PowerShell Scripts — Free Tier*
        - Centrally configure Windows Update policy, push scripts and files via scheduled tasks or Group Policy, no MDM subscription needed
        - Setup: +1–2 days, Group Policy config + script library; +free, works with existing Windows Pro licenses
