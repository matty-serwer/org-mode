- Adding [[id:e8eea4da-a54e-4465-8a03-ffe1ba5f1b55][MCP Server]]s To [[id:35a24719-8497-4359-a239-ed1f1b96a6d2][Claude Code]]
  - Minimal Step-by-Step to Add MCP Servers to Claude Code
    - *List current MCP servers:*
      =claude mcp list= 
    - *Add a remote MCP server:*
      =claude mcp add -d-t http [server_name] [URL]=
      (Add =--header= if API keys needed) 
    - *Add a standard IO MCP server:*
      =claude mcp add [server_name] -- [command] [args]=
      (Add =-e VAR=value= for environment variables) 
    - *On Windows without WSL, replace *=npx=* with:*
      =cmd /c [rest_of_command] @latest= 
    - *Verify connection:*
      Run =claude mcp list= and check =/mcp= in Claude
  - Detailed Setup
    - *Understand MCP Server Types*
      - Local Standard IO servers run on your machine
      - Remote servers use SSE or HTTP transports, hosted remotely [[https://www.youtube.com/watch?v=DfWHX7kszQI&t=30][(00:00:30)]]
    - *Check Existing MCP Servers*
      - Run =claude mcp list= to see current MCP servers [[https://www.youtube.com/watch?v=DfWHX7kszQI&t=300][(00:05:00)]]
    - *Add a Remote MCP Server*
      - Use command:
        =claude mcp add -d-t [http|sse] [server_name] [URL]=
      - Optionally add headers for API keys with =--header= flag
      - Example: Adding Context 7 server for coding docs [[https://www.youtube.com/watch?v=DfWHX7kszQI&t=360][(00:06:00)]]
    - *Verify Server Addition*
      - Run =claude mcp list= again to confirm
      - Open Claude and use =/mcp= command to check connection status [[https://www.youtube.com/watch?v=DfWHX7kszQI&t=450][(00:07:30)]]
    - *Understand MCP Server Scope*
      - Local: available only in current project for current user
      - Project: shared with all team members in the project
      - User: global across all projects for the user
      - Specify scope with =-s [local|project|user]= [[https://www.youtube.com/watch?v=DfWHX7kszQI&t=510][(00:08:30)]]
    - *Add a Standard IO MCP Server*
      - Use command:
        =claude mcp add [server_name] -- [command] [arg1] [arg2] ...=
      - Environment variables can be added with =-e [VAR_NAME]=[value]= flags
      - Example: Adding Context 7 locally with =npx= command [[https://www.youtube.com/watch?v=DfWHX7kszQI&t=600][(00:10:00)]]
    - *Windows Setup Without WSL*
      - If connection fails on Windows without WSL, replace =npx= with:
        =cmd /c [rest_of_command] @latest=
      - Run in Command Prompt instead of other terminals [[https://www.youtube.com/watch?v=DfWHX7kszQI&t=750][(00:12:30)]]
    - *Add Advanced MCP Server with Environment Variables*
      - Example: Bright Data MCP server requires API key and web unlocker zone
      - Add environment variables using multiple =-e= flags
      - Command structure:
        =claude mcp add brightdata -e API_KEY=your_key -e WEB_UNLOCKER_ZONE=zone_name -- npx @brightdata/mcp= [[https://www.youtube.com/watch?v=DfWHX7kszQI&t=840][(00:14:00)]]
    - *Test MCP Servers*
      - Use Claude commands to invoke tools from added MCP servers
      - Approve tool calls when prompted to confirm functionality [[https://www.youtube.com/watch?v=DfWHX7kszQI&t=990][(00:16:30)]]

- OpenCode Overview, Usage, and Supported Models
  How to Use OpenCode
  [[https://www.youtube.com/watch?v=9FW43mb1vTM&t=300][(00:05:00)]]
  Supported AI Models
  [[https://www.youtube.com/watch?v=9FW43mb1vTM&t=120][(00:02:00)]]
  - What is OpenCode?
    - OpenCode is an AI coding agent designed for terminal use.
    - It integrates seamlessly with terminal-based tools like Neovim and Tmux.
    - Helps speed up repetitive coding tasks, answer questions, and make code changes while understanding the full context of the codebase.
    - Allows users to choose their preferred AI model for cost-effective AI assistance in their workflow.
      [[https://www.youtube.com/watch?v=9FW43mb1vTM&t=0][(00:00:00)]]
  - *Installation:*
    - Requires a modern terminal emulator such as Weserm, Elacrity, Ghosty, or Kitty.
    - Can be installed via command line, npm, or package managers like Homebrew.
  - *Setup:*
    - Sign up for Claude Pro or Claude Max plans for cost-effective usage.
    - Run =open code login= to authenticate and authorize OpenCode with your AI provider account.
  - *Workflow Integration:*
    - Use Tmux panes or windows to run OpenCode alongside Neovim and your project.
    - Switch between OpenCode, editor, and project using keyboard shortcuts.
  - *Initialization:*
    - Run =/init= in the project directory to analyze the project and create an =agents.md= file for better AI understanding.
  - *Basic Commands:*
    - Use =/= to list commands and =/themes= to change themes.
    - Ask questions about code or request changes.
    - Two main agents: Plan agent (for questions and planning) and Build agent (for applying changes).
    - Undo and redo changes with =/undo= and =/redo=.
  - *Editing:*
    - Changes made by OpenCode can be viewed and modified in Neovim.
    - Refresh open files in Neovim after changes with =:e!= or =:bufdo e!=.
  - *Sharing:*
    - Share conversations with =/share= or =Ctrl+X S= which copies a URL.
    - Unshare with =/unshare=.
  - *Customization:*
    - Modify configuration via a JSON config file (=opencode.json=) for models, themes, keybinds, and custom agents.
    - Create custom commands using markdown files in a specific directory to automate tasks.
  - Recommended models are from Anthropic, specifically:
    - Claude Pro
    - Claude Max
  - Users can also choose other AI providers such as OpenAI by providing their API keys.
  - Model choice affects cost and performance depending on project size and needs.
