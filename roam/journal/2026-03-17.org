  -----
  - Stem Separation Setup & Workflow
    - Context
      - Goal: extract high-quality 4-stem splits from FLAC files for electronic music production (DnB, sampling, drum replacement)
      - System: MacBook Pro M2 16GB, macOS Sequoia, zsh
      - Test file: Pendulum - Witchcraft (24-bit FLAC)
    - Tool Selection
      - Tried Demucs first — ran into torchaudio backend errors on macOS Apple Silicon (missing soundfile, FFmpeg 7.x incompatibility)
      - Demucs archived Jan 2025, built for torchaudio ≤2.1.x — not worth fixing on modern macOS
      - Switched to UVR5 (Ultimate Vocal Remover)
        - Free, open-source GUI
        - Native macOS ARM64 .dmg
        - MPS GPU acceleration on Apple Silicon
        - Requires the Roformer beta build (not standard v5.6) to access Roformer/MelBand models
    - Model Landscape
      - BS-RoFormer (ByteDance): current SOTA for vocals — 12.9 dB SDR
        - Best model: BS-Roformer-Viperx-1297
      - Mel-Band RoFormer: better than BS-RoFormer for drums and high-frequency content (cymbals, transients)
        - Better mel-scale frequency handling
      - Demucs v4 (htdemucs_ft): still best for bass/drums/other stems specifically
      - MDX-Net: fast, great for clean vocal/instrumental splits, less strong on 4-stem
    - Recommended Models to Download
      - Tier 1 (core workflow)
        - BS-Roformer-Viperx-1297 — best vocals
        - MelBand Roformer | Vocals by Kimberley Jensen — vocal baseline reference
        - htdemucs_ft (Demucs v4) — drums/bass/other
      - Tier 2 (quality refinement)
        - MelBand Roformer Kim | FT 2 Bleedless by Unwa — reduces bleed artifacts
        - BS-Roformer-Viperx-1296 — ensemble pairing with 1297
        - Mel-Roformer-Karaoke-Aufr33-Viperx — lead vs. backing vocal isolation
      - Tier 3 (specialized)
        - MelBand Roformer | Denoise-Debleed by Gabox — post-processing cleanup
        - MelBand Roformer Kim | InstVoc Duality V2 — balanced inst + vocal output
    - Drum Separation
      - drumsep-aufr33-jarredou: MDX23C architecture, outputs 6 individual drum stems
        - Kick, Snare, Hi-hat, Toms, Ride, Crash
        - Validated on acoustic AND electronic drums (64 electronic kits in training set)
        - Use case: drum replacement and layering triggers in Ableton
        - Caveat: kick can bleed with sub bass in electronic music (same frequency range)
      - Workflow: full mix → 4 stems (Roformer + Demucs), then drums stem → 6 drum stems (drumsep)
      - ReStem (rebeatapp.com): paid alternative, bundles Drumagog for in-app drum replacement
    - Processing Performance on M2 16GB
      - Single model (Mel-Band RoFormer): ~3–6 min for a 5-min track
      - Ensemble mode (2 Roformer models): ~7 min — within acceptable range
      - BS-RoFormer ViperX alone can be slow; ensemble of two Roformer models more predictable
    - UVR5 Setup (macOS ARM64)
      - Download Roformer beta build from GitHub releases (not standard v5.6)
      - Gatekeeper bypass:
        
        #+begin_src markup
        sudo spctl --master-disable
        
        #+end_src
      - Quarantine bypass:
        
        #+begin_src markup
        sudo xattr -rd com.apple.quarantine /Applications/Ultimate\ Vocal\ Remover.app
        
        #+end_src
      - Enable GPU Conversion in Settings (activates MPS)
      - Output path: =/Users/lupin/_Workspace/Audio/record-crate/zStems=
      - Models download on-demand via Download Center
    - Recommended Processing Workflow
      - Pass 1: BS-Roformer ViperX 1297 → Vocals + Instrumental
      - Pass 2: htdemucs_ft on Instrumental → Drums, Bass, Other
      - Pass 3 (optional): drumsep-aufr33-jarredou on Drums → 6 individual drum stems
      - Ensemble mode: combine ViperX 1297 + ViperX 1296, Max Spec algorithm, +0.8–1.0 dB SDR improvement
    - Importing Stems into Ableton Live
      - Stems from same separation job are sample-accurate and phase-coherent — no relative drift
      - Import all stems simultaneously (select all, drag to arrangement) to lock relative positions
      - Find first kick transient on drum stem, set as clip start reference across all clips
      - For rigidly quantized electronic music (Pendulum): turn warping off — not needed
      - For live-recorded material with tempo drift: analyze tempo on drum stem, copy warp markers manually to other stems
      - For tempo-flexible playback: use Complex Pro warp mode with shared warp markers across clips
      - Group track or clip grouping keeps all stems moving together when editing
      - Key rule: never separate/ungroup stems after initial placement
