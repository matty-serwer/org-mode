  - Reflect Notes & AI LLMs
    - 🔑 The Big News: Reflect's Official MCP Server (Beta)
      - Reflect now has an official MCP server (currently in beta) that allows AI coding assistants like Claude Code, Codex, and Cursor to search, read, and write to your Reflect notes directly from the terminal or chat interface.
      - This is the *most direct path* and the thing you probably most want to know about.
      - What you can do with it
        - Search notes by text, tag, date, or backlinks
        - Retrieve any note or your daily note
        - Create new notes and append to your daily note
        - Browse and manage tags
      - How to set it up for Claude Code
        - First, enable the MCP server in Reflect's desktop app settings.
        - Then, for Claude Code, run this command in your terminal:
          - #+begin_src markup
                 claude mcp add --scope user --transport http reflect-notes http://127.0.0.1:7676/mcp
              - Reflect also offers a downloadable setup guide markdown file you can upload directly to Claude Code to have it configure itself.
            #+end_src
        - This is a local HTTP MCP server that Reflect's desktop app runs on =127.0.0.1:7676=
          - Reflect's desktop app must be open and running for Claude Code to connect to it.
          - This *bypasses the E2EE limitation* of the REST API because it talks to the local app, not Reflect's servers.
    - 🔒 The Core Limitation: End-to-End Encryption
      - This is the fundamental constraint you need to understand about every other approach.
      - All note-related REST API endpoints are write-only (append only).
        - Your notes' contents are end-to-end encrypted — Reflect's servers can't read the contents of your notes, so they can't serve them up in the API.
      - The REST API cannot read your notes — it's append/write only for note content.
      - The local MCP server is significant because it sidesteps this entirely by communicating with your local app.
    - 🤖 Reflect's REST API — What It Actually Does
      - Reflect's REST API lets you append data to your notes, return a list of bookmarked links, and a few other things.
      - Endpoints from the OpenAPI schema
        - Append to a daily note (with optional list targeting and date)
        - Create a new note
        - List bookmarked links
        - List graphs (your "workspaces")
        - Get user/graph info
        - List Kindle highlights
      - Authentication
        - Uses OAuth 2 with support for PKCE extension so you can build a client without shipping secret keys.
        - You can also generate a simple access token (essentially an API key) from the developer portal.
      - Bottom line on the REST API
        - Good for piping data /into/ Reflect from other tools.
        - Not useful for reading or analyzing your notes.
    - 🛠️ The Third-Party MCP Server (adstastic/reflect-mcp)
      - A community-built Python MCP server on GitHub that wraps the REST API.
      - Installable via =uvx reflect-mcp= with config for Claude Desktop.
      - Tools included
        - =create_note=
        - =append_daily_note=
        - =create_link=
        - =list_graphs=
        - =get_default_graph=
        - =list_links=
        - OAuth2 authentication flow
      - Works in Claude Desktop, unlike Reflect's official MCP which targets Claude Code.
      - Since it's built on the REST API, it still cannot /read/ your notes — it's write-only.
      - Setup for Claude Desktop
        - #+begin_src markup
          {
            "mcpServers": {
              "reflect": {
                "command": "uvx",
                "args": ["reflect-mcp"],
                "env": {
                  "REFLECT_ACCESS_TOKEN": "your_access_token"
                }
              }
            }
          }
            - ## 🧠 Reflect's Built-In AI Features — Full Picture
          #+end_src
      - You've only been using a fraction of what's available.
      - AI Palette (in-editor, per note)
        - Activate with =cmd+j= (or =ctrl+j= on Windows) after highlighting text.
        - Built-in prompts include: list action items, key takeaways, fix grammar/spelling, generate outlines, summarize articles, and more.
        - You can ask anything freeform and save custom prompts.
        - This is what you've been using for single-note editing.
        - Reflect's AI tools let you choose between GPT-4o and Claude 3.5 Sonnet, toggled in preferences.
      - AI Chat with Your Notes
        - Reflect's advanced search lets you chat with your notes using AI.
        - If you have filters selected within the search, the chat function will call on those notes specifically.
          - Filter by the =#person= tag and ask about people in your CRM.
          - Ask about major themes in your notes from the past week.
          - Search a topic and have AI summarize your knowledge on it.
        - This is *cross-note AI* and it's already available to you.
        - The filter-first workflow is the key — you're essentially scoping a RAG query to a subset of your notes.
      - Custom Prompt Templates
        - Reflect added a dedicated Prompt Templates tab in preferences where you can create, copy, edit, and delete custom AI prompt templates.
      - Backlink Decoration via AI
        - Highlight text, open the AI palette with =cmd+j=, and select "Decorate my writing with backlinks."
        - AI automatically adds backlinks to your existing notes throughout the selection.
    - 📦 Built-In Integrations Summary
      - Calendar & Contacts
        - Google Contacts, Google Calendar, iCal, and Office 365 — pulls in meetings and contacts automatically.
      - Zapier
        - No-code connector to hundreds of apps.
        - Add Trello cards, Asana tasks, Google Docs, Slack notes, emails, and tweets to Reflect.
        - Sync Strava data and much more.
      - Readwise
        - Syncs all your Kindle highlights, bookmarks, Twitter saves, podcast highlights, and read-it-later content into Reflect automatically.
      - Also available
        - Kindle direct sync
        - Chrome/browser extension for saving web links (with AI summary generation)
        - Whisper-based voice transcription

      - Write/append to notes from Claude Desktop
        - adstastic/reflect-mcp in Claude Desktop config

        - Reflect's built-in AI Chat + filters
      - Automate piping external data in
        - Zapier + REST API
      - Read notes in Claude Desktop
        - Not possible via REST API; requires official MCP + Claude Code
      - The most interesting work ahead is *setting up Reflect's official MCP in Claude Code*, which would finally give you read access.

    - [[id:aa8cb14a-41fa-43f5-8527-be3a40525e41][Print Folder Structure]] from bash terminal
      - [[id:1f6b1fd6-d3c7-4fa7-9b30-46c5bd11c6ca][tree command]]
        - *Method 1 — All files & folders, full depth*
          - =tree --dirsfirst -a > tree_full.txt=
          - Includes hidden files (=-a=) and all folders/files with no depth limit
          - Safe version that excludes heavy dirs: =tree --dirsfirst -a -I 'node_modules|.git|.next|target|build' > tree_full.txt=
        - *Method 2 — Folders only, full depth*
          - =tree -d --dirsfirst > tree_dirs.txt=
          - =-d= flag limits output to directories only, no files shown
          - Safest to run from broad roots like =~/Projects=
        - *Method 3 — Files & folders, 2 levels deep*
          - =tree -L 2 --dirsfirst > tree_2levels.txt=
          - =-L 2= limits recursion to 2 generations
          - Adjust depth as needed: =-L 1=, =-L 3=, etc.
        - *Bonus — add timestamp + path to output*
          - =echo "$(date) | $(pwd)" > tree_2levels.txt && tree -L 2 --dirsfirst >> tree_2levels.txt=
        - *Install tree if needed*
          - =brew install tree=
