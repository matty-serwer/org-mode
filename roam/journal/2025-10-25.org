- *Overall Setup Notes*
  - Follow these steps sequentially to create the four databases with Phase 1 properties.
  - Use Notion AI by typing "/database" or selecting "Build with AI" when creating each database, then specify the properties as detailed.
  - For relations, ensure bidirectional linking where noted by enabling "Show on [related database]".
  - Colors for Select properties should use Notion's default color options (green for Low, yellow for Medium, red/orange for High/Critical) [11][12].
- *Database 1: Projects*
  - Create a database called "Projects".
  - Add the following properties:
    - Name - Title property (default, already exists).
    - Status - Select property with options: Planning, Active, On Hold, Complete.
    - Priority - Select property with options: Low (green), Medium (yellow), High (red).
    - Start Date - Date property.
    - End Date - Date property.
    - Owner - Person property [11][12].
- *Database 2: Project Docs*
  - Create a database called "Project Docs".
  - Add the following properties:
    - Title - Title property (default, already exists).
    - Type - Select property with options: Requirements, Design, Technical, Meeting Notes, Research.
    - Project - Relation property connecting to the Projects database, with "Show on Projects" enabled to create bidirectional link.
    - Status - Select property with options: Draft, Review, Approved.
    - Last Updated - Last Edited Time property [11][12].
- *Database 3: Epics*
  - Create a database called "Epics".
  - Add the following properties:
    - Name - Title property (default, already exists).
    - Project - Relation property connecting to the Projects database, with "Show on Projects" enabled to create bidirectional link.
    - Status - Select property with options: Backlog, Planning, In Progress, Done.
    - Priority - Select property with options: Low (green), Medium (yellow), High (red).
    - Target Date - Date property [11][12].
- *Database 4: Issues*
  - Create a database called "Issues".
  - Add the following properties:
    - Title - Title property (default, already exists).
    - Type - Select property with options: Story, Bug, Task, Sub-Task.
    - Epic - Relation property connecting to the Epics database, with "Show on Epics" enabled to create bidirectional link.
    - Status - Select property with options: Backlog, To Do, In Progress, Review, Done.
    - Priority - Select property with options: Low (green), Medium (yellow), High (orange), Critical (red).
    - Assignee - Person property.
    - Due Date - Date property [11][12].
