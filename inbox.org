* Creating links inline with org roam
        ## Learn it all at once?
- Yes. Org-roam isn't a separate system. It's plain Org files plus an ID database. Everything you learn in Org still applies.
- The extra learning is about four commands, which you already have bound:
  - `SPC n r f`: find or create a note
  - `SPC n r i`: insert a link (and create the note if it doesn't exist)
  - `SPC n r b`: backlinks panel
  - `SPC n r t`: today's daily note

## Creating a link to a note that doesn't exist yet
`SPC n r i` handles it in one step:
1. In your Ableton note, press `SPC n r i`.
2. Type `Novation LaunchControl XL`.
3. Since there's no match, it asks which template to use (pick `c` concept).
4. A capture buffer opens. Add a line if you want, then press `ZZ` to save, or `ZQ` to cancel.
5. Result:
   - A new file `concepts/2026...-novation_launchcontrol_xl.org` with an ID
   - A link inserted where your cursor was: `[[id:...][Novation LaunchControl XL]]`

### Gotchas
- **Partial match problem:** if what you type partially matches an existing note, Vertico selects that note when you press `RET`. Press `M-RET` instead to use exactly what you typed and create a new note.
- **Selecting existing text:** select "LaunchControl XL" in visual mode, then press `SPC n r i`. The selected text becomes the title and the link text.
- **Turning a heading into a node:** any heading becomes a linkable node once it has an ID. Your `SPC n l` already does this: it creates the ID and copies a link to it.

## Unlinked references
- They don't create links. They're display-only.
- When you open the LaunchControl node and press `SPC n r b`, the panel searches your roam files for its title and aliases appearing as plain text with no link. It lists those spots under "Unlinked References."
- From there, jump to a spot and turn it into a real link by selecting the text, then `SPC n r i`.
- This needs ripgrep with PCRE2 support. Homebrew's `rg` includes it.
